# 비즈니스를 위한 데이터 과학 연구실

> 데이터로 더 나은 비즈니스 결정을 내리려면, 무엇을 알고 무엇을 의심해야 할까?

강의 교안 「비즈니스를위한데이터과학」(전 15주)의 13개 주차와 8·15주차 연습(문제풀이)을 박사 · 조수(하루) · 초파리 연구원 · 주판봇이 진행하는 **AI 연구실 해설 대시보드**로 다시 쓴 시리즈입니다. 페이지마다 브라우저에서 직접 돌려 보는 실험, 초파리 연구원과 주판봇의 대결, 확인 퀴즈, 지식 색인과 온톨로지·서지 꾸러미가 들어 있습니다.

- **바로 보기:** https://adminmrobo.github.io/data_science_for_business/
- 분야: 인공지능(주) · 통계학 · 경영학(보조)

## 데이터와 정확성

- 실험의 데이터는 모두 시드를 고정해 만든 **장난감 데이터**입니다. 캔버스의 노란 도장이 그 표시입니다.
- 교안 본문의 수치와 기업 사례는 교안과 교안이 인용한 자료의 내용이며, 시점이 지난 사례일 수 있습니다.
- 법·규제(개인정보보호법, GDPR, CCPA 등) 내용은 교안 기준이며, 이후 개정 여부를 확인해야 합니다. 이 시리즈는 법률 자문이 아닙니다.
