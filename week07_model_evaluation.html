정확도 95%의 함정

이탈 고객을 한 명도 못 찾는 모델이 정확도 1등을 할 수 있을까?

6주차까지는 정확도 하나로 모델을 채점했습니다. 이번 주는 그 점수를 의심합니다. 이탈 고객이 5%뿐인 데이터에서 혼동행렬을 그리고, 정밀도·재현율·F1, 임계값과 ROC·AUC를 직접 움직여 봅니다. 이어서 모델을 더 좋게 만드는 두 가지 손잡이(앙상블, 학습률·배치)를 돌리고, 마지막에는 "정확도가 높은 모델"과 "돈을 버는 모델"이 같은지 겨룹니다.

왜 정확도 하나로는 모자라나

1. 클래스가 기울어 있다

이탈·사기·불량처럼 비즈니스가 찾고 싶은 쪽은 대개 소수입니다. 전체의 95%가 음성이면 "모두 음성"이라고만 답해도 정확도 95%입니다.[1]

2. 틀림의 값이 다르다

암을 놓치는 오류와 건강한 사람을 다시 검사하는 오류는 무게가 다릅니다. 사기 탐지의 FP는 고객 불편, FN은 금전 손실입니다.[1]

3. 판정 기준은 사람이 정한다

모델은 확률을 내고, "몇 % 이상이면 이탈로 본다"는 임계값은 비즈니스가 정합니다. 기준을 바꾸면 같은 모델의 점수표가 바뀝니다.[1]

큰 그림 — 교안 7주차의 세 교시

평가

모델이 실제 상황에서 얼마나 맞히는지 객관적으로 잽니다. 무엇을 틀리는지까지 보아야 의사결정 품질과 수익성, 리스크 관리로 이어집니다.[1]

최적화

K·C·gamma 같은 하이퍼파라미터, 특성 공학, 여러 모델을 묶는 앙상블, 학습률·배치 같은 학습 방법을 조정합니다. 이 페이지는 앙상블과 학습률·배치를 직접 움직여 봅니다.[1]

1함정

혼동행렬 — 정확도 뒤에 숨은 네 칸

코드: confusion_matrix(y_test, y_pred)데이터: 고객 2,000명(예시)

먼저왜 이 방법을 쓰나

고객 100명 중 실제로 떠나는 사람이 5명뿐이면, "아무도 안 떠난다"고만 말해도 정확도 95%입니다. 정확도 하나로는 모델이 쓸모 있는지 알 수 없습니다. 그래서 맞힌 것과 틀린 것을 종류별로 네 칸에 나눠 세는 표가 혼동행렬입니다.

쉽게 말하면 화재경보기를 평가할 때 "불이 났는데 울렸나 / 안 울렸나", "불이 없는데 울렸나 / 조용했나"를 따로 세는 것과 같습니다.

수식중·고등학생 눈높이로 한 조각씩

TP(참 양성)
실제 이탈 → 이탈이라고 맞힘
FN(거짓 음성)
실제 이탈 → 놓침. 2종 오류
FP(거짓 양성)
실제 유지 → 이탈이라고 잘못 경보. 1종 오류
TN(참 음성)
실제 유지 → 유지라고 맞힘
정확도 = (TP + TN) ÷ 전체
네 칸 중 대각선(맞힌 칸)의 비율
숫자로 한 번 해 보기

100명: TP 6, FN 4, FP 9, TN 81 → 정확도 = (6 + 81) ÷ 100 = 87%. 그런데 실제 이탈 10명 중 4명을 놓쳤습니다. 이 4명이 네 칸으로 나눠야 보이는 숫자입니다.

일상으로 치면

100명 중 1명만 아픈 마을에서 "모두 건강합니다"라고만 말하는 의사는 99% 맞힙니다. 하지만 정작 아픈 1명은 놓칩니다.[1]

머신러닝에서는

혼동행렬은 행에 실제, 열에 예측을 놓은 2×2 표입니다. TP(이탈을 이탈로), TN(유지를 유지로), FP(유지를 이탈로 — 1종 오류, 거짓 경보), FN(이탈을 유지로 — 2종 오류, 누락). 정확도 = (TP + TN) ÷ 전체.[1]

이탈 비율을 바꾸며 두 모델 비교 — 임계값 0.5

5%

풀이

  1. 이탈 비율 5%에서 "아무도 이탈 안 함" 모델은 TP가 0인데 정확도는 학습한 모델과 비슷하거나 더 높습니다.
  2. 혼동행렬을 보면 바로 드러납니다. 왼쪽 표의 위 오른쪽 칸(TP)이 비어 있습니다. 교안의 "95%가 음성인 데이터" 예와 같습니다.[1]
  3. FN이 많으면 그 클래스를 놓치는 경향, FP가 많으면 그 클래스로 과하게 분류하는 경향입니다.[1]

이 칸의 한계: 정확도가 소용없다는 건 알았지만, 대신 무엇을 볼지는 아직 없습니다. → ②칸 정밀도·재현율

교안에서 바꾼 곳: 교안 5쪽의 "TN을 1종 오류 또는 거짓 경보라고도 하는데…"를 이 페이지에서는 "FP를 1종 오류 또는 거짓 경보라고도 하는데…"로 바꿉니다. 1종 오류(거짓 경보)는 실제로는 음성인데 양성이라고 잘못 판단한 경우, 곧 FP입니다.
2기준

정밀도와 재현율 — 임계값을 움직이면

정밀도 = TP ÷ (TP + FP) · 재현율 = TP ÷ (TP + FN)일상: 공항 수하물 검사

먼저왜 이 방법을 쓰나

이탈 고객을 잡으려고 쿠폰을 보낸다면, 두 가지가 궁금합니다. "쿠폰 받은 사람 중 진짜 떠날 사람은 몇 %인가"와 "떠날 사람 중 몇 %에게 쿠폰이 갔나". 앞의 것이 정밀도, 뒤의 것이 재현율입니다. 둘은 한쪽을 올리면 다른 쪽이 내려가서, 어디서 끊을지(임계값)를 업무 비용으로 정해야 합니다.

쉽게 말하면 공항 검색대를 엄격하게 하면 위험물은 다 잡지만(재현율↑) 멀쩡한 가방도 많이 열어 봅니다(정밀도↓).

수식중·고등학생 눈높이로 한 조각씩

학교 수학으로 보면 분수의 분모만 바뀌는 계산입니다. 분자는 둘 다 TP입니다.

정밀도 = TP ÷ (TP + FP)
"이탈"이라고 찍은 사람 중 맞힌 비율
재현율 = TP ÷ (TP + FN)
실제 이탈자 중 잡아낸 비율
임계값
확률이 몇 % 넘으면 "이탈"로 볼지 정하는 기준선. 낮추면 재현율↑ 정밀도↓
F1 = 2 × 정밀도 × 재현율 ÷ (정밀도 + 재현율)
둘 다 높아야 높아지는 평균(조화평균)
숫자로 한 번 해 보기

TP 6, FP 9, FN 4 → 정밀도 = 6 ÷ 15 = 0.40, 재현율 = 6 ÷ 10 = 0.60, F1 = 2 × 0.4 × 0.6 ÷ 1.0 = 0.48.

일상으로 치면

교안의 공항 검색대입니다. 수상한 물건을 모두 추가 검사하면 밀수품은 덜 놓치지만(재현율↑) 멀쩡한 짐도 많이 열어 민원이 늘고(정밀도↓), 검사를 느슨하게 하면 민원은 줄지만 위험물이 빠져나갑니다(재현율↓).[1]

머신러닝에서는

모델은 이탈 확률을 내고, 임계값 이상이면 "이탈"로 판정합니다. 임계값을 낮추면 재현율이 오르고 정밀도가 내려가는 상충관계가 생깁니다. F1은 둘의 조화평균이라 한쪽만 높으면 낮게 나옵니다.[1]

이탈 확률 분포와 임계값 — 고객 2,000명 · 이탈 10%

0.50

풀이

  1. 임계값을 0.2로 내려 보세요. 이탈 고객을 많이 찾지만(재현율↑) 유지 고객도 많이 걸립니다(정밀도↓).
  2. 스팸 필터는 정상 메일을 스팸함에 넣지 않으려 정밀도를, 암 진단·불량품 검출은 놓치지 않으려 재현율을 중시합니다.[1]
  3. 조화평균은 낮은 값에 더 큰 가중치를 줍니다. 정밀도 0.9, 재현율 0.1이면 산술평균은 0.5지만 F1은 0.18입니다.

이 칸의 한계: 임계값 하나마다 점수표가 하나씩 나옵니다. 임계값과 상관없이 모델 자체의 실력을 한 숫자로 비교할 수는 없을까요? → ③칸 ROC·AUC

다중 클래스의 평균 (교안)

macro = 클래스별 점수의 단순 평균 · weighted = 클래스 크기로 가중 평균 · micro = 모든 문제를 합쳐 전체 정답률

교안 예: 수학 80, 영어 70, 과학 90 → macro (80 + 70 + 90) ÷ 3 = 80점. 수학 10문제(80), 영어 5문제(70) → weighted (80×10 + 70×5) ÷ 15 = 76.7점.[1]

3곡선

ROC 곡선과 AUC — 모든 임계값을 한 장에

TPR = 재현율 · FPR = FP ÷ (FP + TN)코드: roc_curve, roc_auc_score

먼저왜 이 방법을 쓰나

임계값을 50%로 할지 30%로 할지에 따라 성적이 달라지니, 모델 두 개를 비교하기 어렵습니다. 모든 임계값의 성적을 한 장의 곡선(ROC)으로 그리고, 그 아래 넓이(AUC) 하나로 비교하면 임계값과 상관없이 어느 모델이 나은지 알 수 있습니다.

쉽게 말하면 선수 두 명을 비교할 때 한 경기 점수보다 시즌 전체 기록을 보는 것과 같습니다.

수식중·고등학생 눈높이로 한 조각씩

학교 수학으로 보면 좌표평면에 점을 찍고, 정사각형(넓이 1) 안에서 곡선 아래 넓이를 재는 것입니다.

TPR = TP ÷ (TP + FN)
재현율과 같음. 세로축
FPR = FP ÷ (FP + TN)

일상으로 치면

교안의 KNN 암 진단 예입니다. 이웃 10명 중 5명이 환자면 암으로 보는 관대한 기준과 7명은 돼야 암으로 보는 엄격한 기준. 기준을 낮추면 환자를 덜 놓치지만(TPR↑) 건강한 사람도 더 잘못 진단합니다(FPR↑).[1]

앙상블 — 여럿이 투표하면 왜 나아지나

배깅 · 부스팅 · 스태킹 · 보팅일상: 여러 전문가의 의견 모으기

먼저왜 이 모델을 쓰나

모델 하나는 특정 실수를 반복합니다. 서로 다른 실수를 하는 모델 여러 개가 투표하면, 각자의 실수가 다수결에서 묻혀 전체가 더 정확해집니다. 이것이 앙상블입니다.

쉽게 말하면 한 명의 의사보다 세 명의 의사가 따로 진단하고 다수 의견을 따르면 오진이 줄어듭니다. 단, 세 의사가 같은 책으로만 공부했다면 효과가 적습니다.

학교 수학으로 보면 고등학교 확률의 「독립시행」(이항분포) 계산입니다.

일상으로 치면

중요한 결정은 여러 전문가에게 묻습니다. 단, 같은 배경의 사람만 모이면 같은 실수를 함께 합니다. 의견이 다양해야 서로의 실수가 상쇄됩니다.[1]

머신러닝에서는

배깅은 복원 추출로 만든 여러 데이터셋에 모델을 하나씩 학습해 평균·다수결을 냅니다(랜덤 포레스트). 부스팅은 앞 모델이 틀린 곳을 다음 모델이 집중해 배웁니다(AdaBoost, XGBoost, LightGBM, CatBoost). 스태킹은 여러 모델의 예측을 메타 모델이 다시 종합합니다.[1]

  1. ρ = 0(서로 독립)이면 정확도 65% 모델 15개의 다수결이 85%를 넘습니다. 모델 하나보다 훨씬 낫습니다.
  2. ρ를 올리면 곡선이 눌립니다. 모두가 같은 문제에서 같이 틀리면 투표해도 소용이 없습니다. 배깅이 데이터를, 랜덤 포레스트가 특성까지 무작위로 바꿔 나무마다 다르게 만드는 까닭입니다.[1]
  3. p를 0.5 가까이 내리면 아무리 모아도 크게 나아지지 않습니다. 앙상블은 "동전보다 나은" 모델들이 있어야 효과가 납니다.

계산 방법

문제 3,000개마다 "공통 난이도" u₀를 하나 뽑고, 각 모델은 확률 ρ로 u₀를, 1 − ρ로 자기 u를 씁니다. u < p 이면 맞힘. 다수결 정확도 = 과반이 맞힌 문제의 비율.

ρ = 0이면 이항분포 P(맞힌 모델 수 > N/2)와 같습니다(콩도르세 배심원 정리).
