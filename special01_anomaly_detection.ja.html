「変」にも種類があります。1人だけ飛び出すもの、組み合わせが合わないもの、どこにも属さないもの、形が違うもの。種類ごとに合う物差しが別にあります。そして物差しで測った後は、「何点から見るか」を決めなければなりません（⑤の欄）。

なぜ異常検知か

1. 異常は少なく、正解表がない

不正決済や誤って入力された伝票は全体の1%ほどで、どれが異常かが前もって印されていることは稀です。そのため7週目の分類のように正解を見て学ぶことは難しく、「普段とどれだけ違うか」を測る方法を使います。[4]

2. 全部は見られない

監査チームが一日に確認できる件数は決まっています。異常検知の実際の役割は「どれから見るか」の順番付けです。

3. 見逃した一件が高くつく

カードの不正利用、設備故障直前のシグナル、ネットワーク侵入のように、一件を見逃すと損失が大きくなります。逆にアラートが多すぎると、人はアラートを無視するようになります。[4]

まず捨てたい誤解 — 「正解率96%なら良い検知器」

⑤の欄の決済574件のうち、異常は24件（約4%）です。何も疑わず「全部正常」とだけ答える検知器でも、正解率は550 ÷ 574 ≈ 95.8%になります。それなのに異常は1件も捕まえられません。異常がまれなデータでは、正解率の代わりに「本当の異常のうち何件を捕まえたか（再現率）」と「アラートのうち何件が本物だったか（適合率）」を見る必要があります（第7週）。

データサイエンスでは

①〜④はすべて、記録一件ごとに異常スコア（普段と違う度合い）を計算する異なる方法です。スコアだけでは何も決まらず、⑤のしきい値を超えた記録だけが「確認すること」になります。インフォグラフィックの要点も同じ構造です。[1]

1一項目

Zスコア — 平均から標準偏差いくつ分離れたか

z = (x − μ) ÷ σ、|z| > τ なら異常データ: 法人カードの食事代決済 200件（例示、異常3件を隠してある）

まずなぜこの方法を使うのか

食事代・出張費・注文金額のように数値一項目だけを見るとき、「この値が普段よりどれくらい飛び出しているか」を同じ目盛りで測りたいのです。金額ごとに散らばりは違うので、そのデータの散らばりをものさしにして測るのがZスコアです。

簡単に言うと身長180cmが「高い」かどうかは、クラスの子どもたちの身長がどれだけばらついているかによって変わります。平均から何センチ（標準偏差）離れているかで測れば、どのクラスでも同じ基準になります。

統計では

z = (x − μ) ÷ σ。データが釣鐘型（正規分布）に近いなら、|z| > 3の値は1,000件に3件ほどしかないので、異常の候補とみなします。インフォグラフィックの釣鐘型の図で、両端の赤い尾がこの領域です。[1]

しきい値τと計算方法を変えてみる

計算
3
博士の考え雲

平均から遠ければ怪しい。ただし、とても大きな値が1つあって「平均」と「ばらつき」を引っ張ってしまうと、物差しが伸びて他の異常が隠れる。そんなときは中央値で測る。

解説

  1. 「平均・標準偏差」でτ = 3だと、48万ウォンの一件だけが引っかかります。11.8万ウォン、9.6万ウォンは目で見ても飛び出していますが通過します。
  2. 理由は、48万ウォンの一件が標準偏差を膨らませたからです。この一件を除くと標準偏差は約1.3万ウォンですが、含めると3.3万ウォンになります。大きな外れ値が他の外れ値を隠すこの現象をマスキング効果と呼びます。
  3. 「中央値・MAD」に替えると、中心は中央値、散らばりは「中央値から離れた距離の中央値 × 1.4826」で測ります。極端な値一つ二つに揺さぶられないので、三件とも現れます。

この項目の限界: Zスコアは一度に一項目しか見ません。「出張一日に出張費108万ウォン」のように項目ごとに見ると普通なのに、二つを一緒に見ると異常な記録は捕まえられません。→ ②項目のマハラノビス距離

計算方法

z = (x − 平均) ÷ 標準偏差 · 頑健なz = (x − 中央値) ÷ (1.4826 × MAD)、MAD = 中央値(|x − 中央値|)

1.4826は、データが正規分布のとき、MADを標準偏差と同じ目盛りに合わせるための定数です。

現場に持ち込むと

監査・財務の現場では、スコアだけを使わず業務ルールと一緒に使います。「週末・深夜の決済」「同じ加盟店に同じ金額の繰り返し」「決裁限度額のすぐ下に分割された決済」のようなルールは理由がはっきりしていて、すぐ確認できます。スコアはルールが思いつかなかったものを探す網として使い、アラートごとに「どの項目が普段とどれだけ違ったか」（例：食事代 z = 5.8）を理由として付けて確認者に渡します。

限界：ルールは知られている手口しか捕まえられず、スコアは理由の説明が弱いです（特に③④項目）。両方を一緒に使うと互いの空白を埋められます。

2関係

マハラノビス距離 — 一緒に動く関係を崩した点

D² = (x − μ)ᵀ Σ⁻¹ (x − μ)、D² > τ なら異常データ: 出張 150件（日数 · 出張費、例示）

まずなぜこの方法を使うのか

出張日数と出張費のように一緒に動く二つの項目は、別々に見ると普通でも、組み合わせがおかしいことがあります。二つの項目の関係を反映して距離を測る方法がマハラノビス距離です。

簡単に言うとラグビーボール形に散らばった点で、ボールの長い方向に遠くある点は「ありうる」点で、短い方向にわずかに飛び出した点は「おかしい」点です。ボールの形に合わせたメジャーを使うわけです。

Σ⁻¹のような記号は難しすぎます。結局何をしているんですか？

学校の数学で見ると座標平面の距離（ピタゴラスの定理）を、データが散らばった方向に伸ばしたり縮めたりして測り直したものです。

x − μ
この点が平均から離れた方向と量（項目二つ分の矢印）
Σ（シグマ）
共分散行列 — 項目ごとの散らばりと、二つの項目が一緒に動く度合いをまとめた表
Σ⁻¹
その表の逆行列 — よく散らばる方向は小さく、あまり散らばらない方向は大きく重みづけする秤

結果。項目が一つならz²と同じ
数字で一度やってみる

二つの項目が互いに関係なく（共分散0）、z₁ = 2、z₂ = 2ならD² = 2² + 2² = 8、D ≈ 2.8。関係の強いデータで一方が +2、もう一方が −2と「逆向きに」飛び出すと、Dはこれよりずっと大きくなります。

助手

データが斜めに散らばっていれば、メジャーも斜めに当てるんですね。一日の出張で108万ウォンがなぜ遠く出るのかわかりました。

日常でいえば

出張が長ければ出張費も多くなります。一日の出張も多いし、108万ウォンの出張費も多いけれど、「一日で108万ウォン」はおかしいです。二つの数字を別々に測らず、「一緒に動く方向」に沿って測ると見えてきます。

統計では

マハラノビス距離は平均ベクトル μ と共分散行列 Σ を使い、データが散らばる方向（楕円）に沿って距離を測り直します。楕円の長い方向には遠くても近く、短い方向にはわずかに外れても遠く出ます。[1][3]

項目ごとに測る「Zの箱」と、関係に沿って測る「楕円」の比較

表示
3

普通の出張関係を崩した出張（助手が隠した3件）長くて高いが関係は合っている7日の出張

博士の考え雲

2つの数字がいつも一緒に動くなら、別々に見ると普通でも「一緒に見たとき」に不自然な記録が本当に怪しい。データの広がった形に合わせて斜めに物差しを当てる。

解説

  1. 四角い箱は日数と出張費をそれぞれZスコアで測った境界です。隠した3件はすべて箱の中にあるので通過し、代わりに関係の合っている7日の出張が箱の外に出てアラートが鳴ります。
  2. 傾いた楕円はマハラノビス距離 D = しきい値の境界です。隠した3件はDが4.8〜6.8で楕円の外の遠くにあり、7日の出張はD ≈ 3.3で境界近くにとどまります。
  3. 項目が二つで、データが正規分布に近いとき、D²は自由度2のカイ二乗分布に従うので、D² > 9（D > 3）となる普通の記録は約1.1%です。

この項目の限界：マハラノビス距離はデータを「平均一つを中心にした楕円一つ」とみなします。少額を頻繁に使う顧客と高額を時々使う顧客のように集団が二つ以上あると、二つの集団の間の空白が逆に平均の近くになるため、近く出てしまいます。→ ③項目の孤立森

計算方法

D² = (x − μ)ᵀ Σ⁻¹ (x − μ) · 二項目なら D² = [a²·s₂₂ − 2ab·s₁₂ + b²·s₁₁] ÷ (s₁₁s₂₂ − s₁₂²)、a = x₁ − μ₁、b = x₂ − μ₂

共分散が0（二項目が一緒に動かない）なら D² = z₁² + z₂² となり、Zスコア二つを足したものと同じになります。

①項目のマスキング効果はここでも起きます。平均ベクトルと共分散を、異常な記録も含めて計算すると楕円が異常の側に膨らむことがあるので、現場では外れ値に揺れにくい方法で共分散を求めること（scikit-learnのMinCovDet、EllipticEnvelopeなど）も併用します。この項目では単純な平均・共分散で計算しました。

3切り離し

孤立森 — 何回切れば一人になるか

s(x) = 2^(−E[h(x)] ÷ c(n))、1に近いほど異常データ: 決済 292件（決済金額 · 一日の決済回数、二つの集団、例示）

まずなぜこのモデルを使うのか

顧客が「少額を頻繁に使う集団」と「高額を時々使う集団」に分かれていると、平均は二つの集団の間の空白に置かれます。平均を基準に測る①②は、その空白の異常を見逃します。距離を測らず「どれだけ簡単に切り離されるか」で測る孤立森を使います。

やさしく言うと 20の扉で、「人の群れに混じった人」は当てるまでに質問がたくさん必要ですが、「1人で離れた所にいる人」は2、3回で当たります。質問の数が少ないほど異常です。

  2. c(n)はn件で作った木で「平均的な点」の経路長です（n = 256なら約10.2）。E[h(x)]がc(n)と同じならs = 0.5、ずっと短ければ1に近くなります。元の論文では、すべての点が0.5近くなら、はっきりした異常はないと見ます。[2]
  3. 背景を「マハラノビス距離」に替えると、二つの集団の間の空白が暗く（平均に近く）塗られます。平均がまさにその空白にあるからです。白い輪（スコア上位12件）も空白の赤い点をほとんど素通りして、外側の点にだけ付きます。孤立森の背景では、白い輪が空白の赤い点の多くに付きます。

この項目の限界：孤立森は項目ごとに別々に切ります。一日24時間の来店者数のように項目が多く「項目が作る形」が重要なデータでは、時間帯ごとの値は普通でも形がおかしい日をうまく切り離せません。→ ④項目の再構成誤差

計算方法

c(n) = 2H(n − 1) − 2(n − 1) ÷ n, H(i) ≈ ln(i) + 0.5772 · s(x, n) = 2^(−E[h(x)] ÷ c(n))

木は深さ log₂(256) = 8で止まり、それまでに一人になれなかった点には、残りの点数 m に対する c(m) を足して経路長を埋めます（元の論文の方法）[2]。インフォグラフィックの木の図の h = 2、3は、この足し算を省いた簡略図です。

この項目のオートエンコーダーについて

この項目のオートエンコーダーは、層に曲線（非線形）の関数がない直線オートエンコーダーです。直線オートエンコーダーを二乗誤差で学習すると、主成分分析（PCA）が見つける軸と同じ空間を学ぶことが知られているため[5]、ここでは正常140日の共分散から主成分を求めて直接計算しました。ボトルネック k = 主成分 k 個です。

現場のオートエンコーダーは、曲線の層を何層も重ね、直線では要約できない複雑なパターンも学びます。その代わり学習に時間がかかり、ボトルネックや層の数を決めるための試行錯誤が必要です。

よくある誤解3つ

「異常 = 不正」？

違います。異常は「普段と違う」という意味にすぎません。②の欄の7日間の出張のように、長くて高額でも正当な記録もアラートに引っかかります。アラートは「確認してみるもの」であって「間違ったこと」ではありません。アラートだけで人を疑うことはしません。

「正解率が高ければ上手に捕まえる」？

違います。異常が4%だけなら、「全部正常」とだけ答えても正解率は96%です。再現率と適合率、そしてアラートの件数を合わせて見ます。

「複雑な道具がいつも優れている」？

違います。対決で孤立森が勝ったのは、群れが2つあるデータだったからです。①の欄のように群れが1つで異常が片方の端にあるなら、中央値で測ったZスコアで十分で、理由を説明するのも簡単です。

)
labels = model.fit_predict(X)   # X: 数値の表（行 = 記録、列 = 項目）
# labels: 異常なら -1、正常なら 1
scores = model.score_samples(X) # 低いほど異常（原論文のスコアと符号が逆）
  • contaminationは「このデータに異常が5%ある」という事実を見つける値ではなく、学習データのスコアの上位5%の地点にしきい値を置け、という指示です。⑤項目の「上位p%」の方法と同じです。実際の異常が1%でも10%でも、学習データの約5%に−1が付きます。既定値は「auto」で、原論文の基準を使います。[6]
  • score_samplesは原論文のスコア s(x) の符号を反転させた値なので「低いほど異常」です。このページの s(x) は原論文どおり「1に近いほど異常」です。インフォグラフィックのメモ（Note）もこの違いを指摘しています。[1][6]
  • 木の数（n_estimators）の既定値は100、木ごとに抽出する件数（max_samples）の既定値は256とデータ件数のうち小さい方です。このページも同じ値を使っています。[6]

実験を終えて

博士

今日確認したことは三つです。

  • 異常検知は、スコアを作ることと、しきい値を決めることの二段階である。
  • 道具はデータの形で選ぶ。一項目ならZ、関係ならマハラノビス、集団が複数なら孤立森、パターンなら再構成誤差。
  • しきい値は、確認できる人員と見逃したときの損失が決める。
アバボット

群れの間に隠れたのは森が見つけたよ。木100本、元を取った。

ショウジョウバエ研究員

…平均が空白にあると、自分の物差しが曲がるのか。認める。でも①項目のように集団が一つなら、私の物差しで十分だ。

助手

アラートの後には人が確認します。確認結果を集めれば、7週目の分類モデルへ移れます。一緒に見ると良いのは3週目（外れ値の扱い）と7週目（適合率・再現率）です。
