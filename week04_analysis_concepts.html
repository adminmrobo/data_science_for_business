왜 도구와 알고리즘을 따로 배우나

1. 도구가 프로젝트를 좌우한다

교안은 도구 선택이 분석 프로젝트의 성공을 결정하는 핵심 요소라고 말합니다. 맞지 않는 도구를 고르면 분석 효율과 결과 품질이 크게 떨어집니다.[1]

2. 규칙을 누가 만드는가

전통적 프로그래밍은 사람이 규칙을 적고, 머신러닝은 데이터와 과거 결과에서 규칙을 찾습니다. 같은 대출 심사라도 만드는 방식이 다릅니다.[1]

3. 문제 유형이 모델을 고른다

3주차에서 정한 분류·예측·군집·연관·최적화 유형마다 어울리는 알고리즘과 평가 지표가 있습니다.[1]

2방법

규칙 기반과 머신러닝 — 신용대출 심사

비교: 사람이 쓴 규칙 vs 데이터에서 배운 규칙교안 사례: 은행 신용대출

은행에서는

전통적 방식은 데이터를 보고 전문가와 담당 직원의 의견을 반영해 판단 기준을 직접 입력합니다. 머신러닝은 데이터와 과거 결과(정상 상환·연체)로 판단 기준을 자동으로 만들고, 그중 결과가 가장 좋은 기준을 고릅니다.[1]

머신러닝에서는

규칙 기반은 로직이 명확하고 예측 가능하지만 유연성이 부족합니다. 머신러닝은 복잡한 패턴과 새 데이터에 적응하지만, 해석이 어렵고 대량의 학습 데이터가 필요합니다.[1]

풀이

  1. 장난감 세계의 진짜 규칙은 "소득이 높을수록 감당할 수 있는 부채비율도 높아진다"는 비스듬한 경계입니다(8%는 무작위로 뒤집힌 예외).

  3. 머신러닝(KNN, K = 15)은 과거 기록에서 경계 모양을 그대로 배웁니다. 대신 "왜 거절했나"를 한 줄 규칙으로 설명하기 어렵습니다.

현장에 옮기면

교안은 규제 준수와 설명 가능성이 중요한 분야에서는 해석 가능한 모델을 선택하라고 합니다.[1] 신용평가처럼 거절 사유를 설명해야 하는 업무는 성능과 해석 가능성 사이의 균형을 정해야 합니다.

모형의 한계: 실제 신용평가는 수많은 변수와 규제 요건을 쓰며, 이 2차원 장난감과 다릅니다.

생성 AI로 치면

"이런 경우엔 이렇게 답하라"는 규칙 목록(프롬프트)으로 챗봇을 만들 수도 있고, 예시 데이터로 모델을 미세조정할 수도 있습니다. 같은 선택입니다. 규칙은 설명하기 쉽고, 학습은 예외를 더 잘 다룹니다.

비유의 한계: 대형 언어 모델은 이미 방대한 데이터로 학습되어 있어 규칙과 학습의 경계가 이 실험처럼 깔끔하지 않습니다.

3검증

데이터 분할과 교차 검증 — 외운 것과 배운 것

방법: 훈련·검증·시험 분할, 5겹 교차 검증연구실: 봉인한 시험지

연구실에서는

연습 문제만 달달 외운 학생은 연습 문제로 치면 100점이지만, 처음 보는 시험지에서는 무너집니다. 그래서 시험지는 따로 봉인해 둡니다.

머신러닝에서는

훈련 데이터만 너무 잘 외워 새 데이터에 대응하지 못하는 현상이 과적합입니다. 교안은 훈련·검증·시험을 60:20:20 또는 70:15:15로 나누고, 교차 검증으로 제한된 데이터를 최대한 활용하라고 합니다.[1]

풀이

  1. K = 1이면 모든 훈련 기록이 자기 자신을 이웃으로 삼아 훈련 정확도가 100%입니다. 예외 8%까지 외워 경계가 울퉁불퉁해집니다.
  2. 5겹 교차 검증은 600건을 다섯 묶음으로 나눠, 한 묶음씩 번갈아 검증용으로 쓰고 나머지로 학습합니다. 다섯 점수의 평균과 흩어짐을 함께 봅니다.[1]
  3. K는 교차 검증 점수로 고르고, 봉인한 시험 데이터 400건은 마지막에 한 번만 씁니다. 시험 점수로 K를 고르면 시험지를 미리 본 셈입니다.
  4. K가 너무 작으면 과적합, 너무 크면 경계가 뭉개지는 과소적합입니다.[1]

홀드아웃(한 번 나눠 한 번 평가)은 빠르지만 나누는 방법에 따라 결과가 흔들립니다. 부트스트랩은 복원 추출로 여러 표본을 만들어 성능의 분포를 봅니다.[1]

K = 1의 훈련 점수 100%는 답안지를 보고 푼 점수예요. 교차 검증 막대를 보세요.

마트에서는

라면을 산 손님이 달걀도 함께 사는지 봅니다. 교안의 예: 손님 5명 중 라면 3명, 달걀 4명, 둘 다 3명.[1]

데이터 과학에서는

지지도 = 둘 다 산 비율, 신뢰도 = 라면을 산 사람 중 달걀도 산 비율, 향상도 = 신뢰도 ÷ 달걀의 전체 구매 비율. 향상도가 1보다 크면 우연보다 함께 잘 팔립니다.[1]

장바구니 계산기 — 칸을 눌러 구매를 바꿔 보기

규칙

풀이

  1. 교안 예시 그대로면 지지도 3/5 = 0.6, 신뢰도 3/3 = 1.0, 향상도 1.0 ÷ (4/5) = 1.25입니다. 함께 구매될 가능성이 우연보다 25% 높습니다.[1]
  2. 신뢰도가 높아도 달걀을 거의 모든 사람이 산다면 향상도는 1에 가깝습니다. "누구나 사는 물건"과의 연관은 정보가 없습니다.
  3. Apriori는 자주 팔리는 상품부터 단계별로 조합을 찾고, FP-Growth는 트리 구조로 더 빠르게 찾습니다.[1]

이 칸의 한계: 손님 5명의 연관은 우연일 수 있습니다(1주차 ④칸의 표본 크기). 그리고 어떤 모델을 고르든 그 판단이 공정한지, 설명할 수 있는지는 따로 따져야 합니다. → 정리의 윤리적 고려
